## 🔍 Asset Metadata Format

Each asset includes:
- **Function**: What it does
- **Original Goal**: Intended purpose
- **Status**: wiederverwendbar/veraltet/ersetzbar
- **Migration Effort**: niedrig/mittel/hoch
- **v3.1 Compatibility**: direkt/anpassbar/neu entwickeln
- **Dependencies**: External requirements
- **Context**: Links to documentation/screenshots
