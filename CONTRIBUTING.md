# 🤝 Beitrag zu Clara360 – CONTRIBUTING Guide
*Erstellt: 2025-06-26_11-34-59*

Vielen Dank für dein Interesse an einem Beitrag zu Clara360!  
Dieser Leitfaden hilft dir, effizient Aufgaben zu übernehmen, Pull Requests zu erstellen und im Team zusammenzuarbeiten.

---

## 🔀 Branch-Strategie

- `main` → produktiver Code (nur durch PRs)
- `dev` → aktueller Entwicklungsstand
- `feature/<topic>` → pro Task oder Feature
- `hotfix/<bug>` → für kritische Fehlerbehebungen

---

## ✅ Schritte zum Mitwirken

1. Issue übernehmen oder eigenes eröffnen (mit Beschreibung & Ziel)
2. Feature-Branch erstellen (`feature/komponentenstruktur`)
3. Lokale Änderungen inkl. Tests & Linting durchführen
4. Pull Request gegen `dev` eröffnen (mit PR Template)
5. Review abwarten, ggf. Änderungen vornehmen

---

## 🧪 Testen & Qualität

- Nutze `npm run lint` und `npm run test` lokal vor jedem Commit
- PRs ohne erfolgreiche CI-Checks werden nicht gemerged
- Klarer, dokumentierter Code ist Pflicht (inkl. Kommentare bei komplexer Logik)

---

## 💬 Kommunikation

- Bitte nutze klare Commit-Nachrichten
- Füge Screenshots oder GIFs bei UI-Änderungen bei
- Stelle Fragen im Pull Request oder verlinke Issues

Danke für deinen Beitrag zum Clara360-Ökosystem!
